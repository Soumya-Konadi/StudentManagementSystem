# Student Management System

A console-based Student Management System developed using Java, JDBC, DAO, and MySQL.

## Features
- Add new students
- View all student records
- Search students by ID
- Update student details
- Delete student records

## Technologies Used
- Java
- JDBC (Java Database Connectivity)
- MySQL
- Eclipse IDE
- MySQL Connector/J

## Database Setup
1. Create a MySQL database named `student_db`.
2. Create a table named `students` with columns for ID, name, age, email, and course.
3. Configure the database connection in `DBConnection.java`.
4. Add the MySQL Connector/J driver to the Java project.

## How to Run
1. Import the project into Eclipse.
2. Configure MySQL credentials in `DBConnection.java`.
3. Ensure the MySQL server is running.
4. Run `Main.java` as a Java Application.

## Project Purpose
This project demonstrates Java database connectivity, DAO design, and CRUD operations using MySQL.
